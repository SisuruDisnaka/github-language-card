# GitHub Language Stats Card

Auto-updating GitHub language statistics card as a PNG image.


---
## 🔗 Usage

```md
![Language Stats](https://sisuru-lang-card.vercel.app/api/languages?username=YOUR_USERNAME)
```
---

## 🚀 Run Locally

```bash
npm install
node server.js
```
